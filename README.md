# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

顶栏「班次窗」管理班次：检查员开启命名班次时必须填写起止时刻，服务端按服务器当前时刻判断——只有时刻落在起止闭区间内且班次仍为开启中才允许上报；时刻在窗外或班次已关闭都会被拒绝并注明原因。同时只允许一个开启中的班次，开新班前必须先关闭旧班。关闭会写入大事记（班次名、关闭人、关闭时刻）。旁观账号能看班次列表和大事记，但不能开启、关闭或改窗。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 顶栏点「班次窗」，开启「夜班」，起止设成此刻前后各一小时；回报测点页报「东翼」0.4，应放行。
5. 在班次列表对夜班「改起止」，把起止都改成早于此刻（不关班），再报东翼 0.4，应被拒绝且原因含「窗外」。
6. 关闭夜班，大事记出现一条关闭事项，含班次名、关闭人、关闭时刻；此时再报东翼 0.4，应被拒绝且原因含「已关闭」。
7. 夜班未关闭时尝试再开新班，会被拒绝并提示先关闭；viewer 登录班次窗只能看，没有开启表单和关闭/改窗按钮。
