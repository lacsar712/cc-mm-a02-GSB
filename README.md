# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 班次窗

上报受班次窗约束：检查员先在顶栏「班次窗」里开启一个命名班次（必填起止时刻），服务端按服务器当前时刻判断，只有落在起止闭区间内且班次仍为开启态才允许上报；落在窗外或班次已关闭一律拒绝，并写明是窗外还是已关闭。同一时刻只允许一个开启中的班次，再开新班必须先关闭旧班。关闭时写入大事记（班次名、关闭人、关闭时刻）。班次列表展示名称、起止、开启人、状态。旁观账号能看班次列表和大事记，不能开启或关闭。

## 验收

1. 用 gasman 登录，顶栏进「班次窗」，开夜班并把起止设成此刻前后各一小时，报东翼 0.4 应放行。
2. 再把该班起止改成已全部早于此刻，不关班再报，应被拒且原因含「窗外」。
3. 关闭夜班，大事记里出现该班次的关闭记录（班次名、关闭人、关闭时刻）；此时再报仍被拒且原因含「已关闭」。
4. viewer 登录后能看班次列表和大事记，但没有开启/关闭按钮，也没有上报表单。
5. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
